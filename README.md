Vice City Cover Maker — turn a photo and a caption into GTA 6-style multi-panel cover art with a sunset/neon grade, exported as a PNG to share. Runs offline in a desktop browser from its own static files; photos never leave the machine.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser. Load a photo (or use a built-in sample), arrange it across the panels, write the caption, pick a post size (1080 x 1080, 1080 x 1350 or 1920 x 1080), and export a PNG.
