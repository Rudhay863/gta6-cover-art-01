# Fonts

- `LiberationSans-Bold.ttf` and `LiberationSans-Regular.ttf` — the Liberation
  font family, licensed under the SIL Open Font License 1.1, which allows
  redistribution with the app. Copies taken from the system font directory
  (`/usr/share/fonts/truetype/liberation/`).
- The app loads them only from these files under `app/fonts/`; no font is
  fetched from the network and no game font is used anywhere.
